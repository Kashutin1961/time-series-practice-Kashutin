Данный репозиторий содержит набор Jupyter‑ноутбуков, созданных в рамках курса Data Science от SkillFactory, модуль PDA‑2: Обработка временных рядов.

Цель работы
Практическая работа демонстрирует, как различные методы прогнозирования ведут себя на реальных временных рядах.
Основные задачи включают:

Изучение структуры временного ряда

Построение статистических и ML‑моделей прогнозирования

Сравнение качества моделей

Визуализация предсказаний

Освоение лучших практик разбиения временных рядов на train/test

Эксперименты с генерацией признаков (лаги, праздники, сезонные паттерны)

Ноутбуки были адаптированы из различных учебных материалов (включая пример прогнозирования нагрузки PJME) и переработаны для работы с ежедневными данными продаж из курса SkillFactory.
