Time Series Analysis — Practical Work (SkillFactory Module 15, HW‑03)
This repository contains a set of Jupyter notebooks created as part of the SkillFactory Data Science course, module PDA‑2: Обработка временных рядов.
The goal of the practical work was to explore different approaches to time‑series analysis and forecasting using real datasets.

Contents
1. decomp_air_Kashutin.ipynb
Classical decomposition of time series:

Trend extraction

Seasonal component

Residual analysis

Visualization of decomposition results

2. arma_arima_Kashutin.ipynb
Statistical forecasting models:

ACF/PACF analysis

AR, MA, ARMA, ARIMA model fitting

Model diagnostics

Forecast evaluation

3. prophet_tutorial_Kashutin.ipynb
Forecasting with Facebook Prophet:

Automatic trend/seasonality detection

Holiday effects

Cross‑validation

Future forecasting

4. time-series-xgboost_Kashutin.ipynb
Machine‑learning approach to time series:

Feature engineering (lags, date features, holidays)

XGBoost regression

Train/test split for time series

Forecast visualization

Comparison of metrics

Purpose of the Work
This practical module demonstrates how different forecasting techniques behave on real time‑series data.
The tasks include:

Understanding time‑series structure

Building statistical and ML‑based forecasting models

Comparing model performance

Visualizing predictions

Learning best practices for time‑series train/test splitting

Experimenting with feature engineering (lags, holidays, seasonal patterns)

The notebooks were adapted from various tutorials (including PJME electricity load forecasting) and rewritten to work with daily sales data from the SkillFactory course.
